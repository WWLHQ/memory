## 第四部分 · REQ-006 五个子页

### P8 记忆管理（`/memory.html`）

15. 列表 7 条种子记忆：置信度进度条、状态徽章（六态）、置顶 icon
16. **G4 锁定约束**：locked 行（mem_005）操作按钮全部禁用，「解锁」可用
17. 点「记住」→ toast「已提升这条信息的优先级。」（17.3 文案）
18. 点行 → 右侧详情抽屉；**content 可内联编辑**；重要度/置信为**只读进度条**（无滑杆，17.4 程序通道控制，调整入口在 P4 生命周期页）

### P2 写入（`/write.html`）

19. 输入内容时右上**实时 token 估算**变化
20. 选分类 → 下方分类预览卡联动；输标签 → 建议列表出现

22. 粘贴与种子 mem_001 相同内容 → 查重卡出现 **5 维度条形图** + 综合分超阈值，三个按钮（合并/覆盖/保留）
23. 点提交 → **L1~L6 六层回执**依次显示（L1 标注仅审计）

### P11 审计日志（`/audit.html`）

24. 列表 8 条种子，含 15 种 action 的下拉筛选可用
25. 多条件过滤（action + 关键词）→ 结果联动；「重置」清空
26. 点任一 `request_id`（如 req_a1）→ 展开**同链路 3 行**（18.2-E）
27. 点「导出 CSV」「导出 JSON」→ 浏览器下载文件，打开内容正确（中文不乱码）

### P4 生命周期（`/lifecycle.html`）

28. 列表 7 条覆盖六态：active/hibernating/archived/deprecated/stale/dormant 徽章颜色区分
29. 选中记录 → 卡片显示状态机高亮 + 可迁移目标；deprecated 行有 replaced_by 链接
30. 调参面板：拖半衰期滑杆 → **新鲜度预览实时变化**；locked 记录 → 全部滑杆/开关置灰（G4）
31. 勾选多条 → 「批量迁移」按钮激活，执行后出 toast + 审计

### P7 冲突裁决（`/dispute.html`）

32. 队列 5 条冲突，四类徽章（直接矛盾红/部分重叠黄/语境相关蓝/不确定灰）

34. 点队列项 → 下方裁决面板显示旧/新对比（含各自 id 与置信度）
35. 点「自动覆盖」→ toast「旧值 deprecated…」+ 裁决历史出现成对记录（old_id+new_id+req_d 链）
36. 其余三个按钮（人工确认/合并/挂起）点击均有对应 toast 与历史
