# Agent 接入配置页 — 字段级交互规格

> 配套：《需求规格书》第 19 章、《需求规格书_UI页面设计》第 10 章。
> 把 Agent 接入配置页每个控件的**默认值、校验、联动、异常态文案、边界约束**定死到字段级，供开发与验收对照。
> 章节号引用以规格书为准（19.x / 13.4 / 5.1 / 5.2 / 4.1 / 18.2）。

## 0. 页面状态

```
ONBOARD（未配置） ──填密钥+选通道──> CONFIGURED（已配置） ──测试通过──> CONNECTED（连通）
                                        │ 测试失败/熔断 OPEN
                                        └─> DEGRADED（降级，仅补偿通道可用）
```

- 每家 Agent 一个接入卡片，卡片头带**接入优先级徽标**（19.2）：`MVP·P0`（deepseek harness/workbuddy）/ `MVP·P1`（Claude Code）/ `兜底·P2`（Codex）/ `扩展·P3`。
- 卡片状态：ONBOARD / CONFIGURED / CONNECTED / DEGRADED。

## 1. 接入卡片（每家 Agent 一份）

### 1.1 卡片头字段
| 字段 | 控件 | 默认 | 校验 | 联动 | 异常态文案 |
|---|---|---|---|---|---|
| `agent_name` | 文本 | — | 枚举 {deepseek harness, workbuddy, Claude Code, Codex, …}（19.2） | 选 Agent 后载入其接入方式能力矩阵 | — |
| 接入方式 | 标签组 | MCP+Webhook（自有）/ MCP（Claude Code）/ API 拉取（Codex） | 按 19.2 接入方式列 | 决定 §3 通道可用项 | — |
| 连通成功率 | 进度条 | — | 12.1：<95%（5min 窗口）⚠️ | 低于 95% 卡片变黄 | 「连通率 <95%，请检查 Agent 网络」 |
| 熔断状态 | 状态点（5.2） | CLOSED | CLOSED（绿）/ OPEN（红，严重）/ HALF_OPEN（黄） | OPEN 时禁用「测试」 | 「熔断 OPEN：连续失败≥5，已停止主通道，仅补偿通道」 |

| `enterprise_id`/`team_id` | 只读（全局注入） | 全局租户上下文（0.1） | **禁止手填**（R1） | — | — |
| 接入优先级 | 徽标（19.2） | 按 Agent 自动 | P0/P1 为 MVP，P2 兜底 | — | — |

### 1.2 单 Agent 操作
| 操作 | 触发 | 行为 | 文案 |
|---|---|---|---|
| 测试接入 | 点「测试」 | 发 `recall_memory` 测试请求，显示返回样例 + `request_id`（18.2-E） | 「测试成功：req_xxx 已记审计」 |

## 2. 一键全量接入（19.9，顶部主按钮）

### 2.0 发现流程
```
[⚡ 自动发现并接入本机 Agent]
   ① 扫  发现信号源(可勾选)：MCP 注册表 / 本机进程 / Webhook 心跳 / 手动兜底
   ② 分  自动打标 19.2 优先级：自有=P0 / 第三方=P1 / 兜底=P2
   ③ 绑  按 19.4/19.5 默认值直接绑定（隔离/双通道/反代理模型映射，无需逐项设置）
   ④ 验  逐个测通 + 审计 auto_bind · agent:<name> · signal:<源>
```
| 字段 | 控件 | 默认 | 校验 | 联动 | 异常态文案 |
|---|---|---|---|---|---|
| `⚡ 一键接入` 按钮 | 主按钮 | 可点 | 本机可授权 Agent ≥1 | 点击触发 ①扫→②分→③绑→④验 四段进度条 | 「未发现 Agent：仅手动兜底可用」 |
| 发现信号源 | 复选组（4 项） | 全开 | 手动兜底可单独关 | 勾选决定①扫哪些源 | 全关=只能手动加 |
| 进度条（4 段） | 只读 | — | — | 扫/分/绑/验 逐段亮 | 段失败定位到源 |
| 自动绑定结果卡 | 每 Agent 一卡 | — | — | 标「自动发现·已绑定·可撤销」+ ✓/⚠ + 信号来源 | 测通失败=⚠ 待手动补 |
| 撤销绑定 | 每卡按钮 | — | 写审计 unbound | 撤销后回到 ONBOARD | 「已撤销，恢复需重跑一键接入」 |

### 2.1 绑定默认值（用户无需逐项设置）
| 项 | 默认 | 出处 |
|---|---|---|
| 隔离粒度 | project_id 共享 + user_id 偏好 | 19.4 |
| 采集通道 | 双通道（Webhook 主 + API 拉取补偿） | 5.1 / 19.3 |
| 反代理模型 | 该 Agent 免费/低价模型自动进 19.8 全量映射池 | 19.8 |
| 安全默认 | **只读召回**；写入/反代理 P0/P1 按 19.2 放行，**P2 须用户确认** | 19.9 R1 |

## 3. MCP 工具配置（19.5，须携带 project_id + user_id）

| 工具 | 参数 | 默认 | 可配 | 校验 | 异常态 |
|---|---|---|---|---|---|
| `recall_memory` | `query`,`top_k`,`project_id`,`user_id`,`scene`,`mode?` | `top_k=5`、`scene=default` | 启用开关、`top_k`(1–10)、默认 `scene`、默认 `mode`(null=自动) | `top_k` 越界钳制；`scene=critical` 时 `mode` 不得为 `minimal`（16.5，同检索页 R5） | 「critical 禁极简，已回落 null」 |
| `write_memory` | `content`,`category`,`project_id`,`user_id`,`session_id` | 默认 `category=work` | 启用开关、默认 `category` | `category` 枚举（17.6 六类）；`project_id` 必填（19.4） | 缺 project_id 不可保存 |
| `get_user_preferences` | `user_id` | — | 启用开关 | `user_id` 必填 | — |

- **隔离粒度开关（19.4）**：
  | 开关 | 默认 | 联动 | 文案 |
  |---|---|---|---|
  | 项目层按 `project_id` 共享（跨 Agent） | 开 | 关则该项目记忆仅单 Agent 可见 | 「关闭后该项目记忆不再跨 Agent 共享」 |
  | 个人偏好跨项目共享（user_id 级） | 开（MVP 定案） | 关则个人偏好挂到 project_id | 「关闭后个人偏好随项目隔离」 |
  | `user_id` 仅隔离个人偏好 | 开（9.2 微信式） | 固定语义，仅展示 | — |

- 保存前校验：**`recall_memory`/`write_memory` 必须带 `project_id`**，否则禁止保存（19.5 红线）。

## 3. 采集通道配置（5.1 / 19.3 双通道）

| 控件 | 默认 | 校验 | 联动 | 异常态 |
|---|---|---|---|---|
| 主通道 Webhook 开关 | 开 | 自有/Claude Code 可用；Codex 受限（19.2） | 主通道 OPEN 熔断时自动转仅补偿 | 「主通道熔断，已降级为仅补偿通道」 |
| 补偿通道 API 拉取开关 | 开 | 全 Agent 可用 | 与主通道 5min 对账 | 「补偿通道 5min 内补齐缺失」 |
| 对账周期 | 5min 短周期 + 每日全量 | 枚举 {5min, 15min, 30min} + 每日全量固定 | 改短周期即时生效 | — |
| 幂等去重（SHA-256） | 开（固定） | 5.4，不可关 | — | — |

- **DEGRADED 态**：主通道 Webhook 熔断 OPEN → 卡片状态 DEGRADED，仅补偿通道工作，提示「延迟 5min，数据完整性不受影响（5.4）」。

## 6. 校验规则（前端）

1. **R1 租户禁手填**：`enterprise_id`/`team_id` 只读，来自全局租户上下文。
2. **R2 project_id 必填**：保存任何 MCP 工具配置时，`recall_memory`/`write_memory` 的 `project_id` 缺失 → 禁保存。
3. **R3 critical 禁极简**：默认 `scene=critical` 时默认 `mode` 不得为 `minimal`（16.5）。
4. **R4 双通道至少开一**：主通道 + 补偿通道全关 → 禁保存（记忆库需可采集，5.1）。
5. **R5 密钥不回流**：API Key 界面恒脱敏，轮换后旧 Key 按宽限期失效。
6. **R6 熔断联动**：熔断 OPEN 自动降级 DEGRADED，UI 显示降级提示而非报错。

## 7. 边界约束（实现红线）

| # | 约束 | 来源 |
|---|---|---|
| R1 | 租户 ID 仅全局注入，前端禁手填 | 0.1 / 18.2-A |
| R2 | 记忆读写必带 `project_id`（跨 Agent 共享锚） | 19.4 / 19.5 |
| R3 | `user_id` 仅隔离个人偏好 | 19.4 / 9.2 |
| R4 | 双通道至少开一，SHA-256 幂等不可关 | 5.1 / 5.4 / 19.3 |
| R5 | 主通道熔断 → 自动降级仅补偿，不丢数据 | 5.2 / 19.3 |
| R6 | 密钥脱敏，轮换走宽限期 | 4.1 |
| R7 | 每家 Agent 测试必记 `request_id` 审计 | 18.2-E / 4.3 |
| R8 | **一键自动绑定默认只开只读召回**；写入/反代理敏感动作 P0/P1 按 19.2 放行、**P2 须用户确认** | 19.9 |
| R9 | 每个自动绑定**可一键撤销**（审计 `unbound`），仅无信号 Agent 才需手填端点 | 19.9 |
| R10 | 发现范围限**本机用户授权**的 Agent，不跨机器/不爬公网 | 19.9 |

## 8. 验收用例（摘要）

| 用例 | 操作 | 期望 |
|---|---|---|
| MVP 接入 | 配 deepseek harness + Claude Code，双通道开 | 两卡片 CONNECTED，优先级徽标 P0/P1（19.2） |
| 隔离配置 | 开「个人偏好跨项目共享」 | 个人偏好按 user_id 跨 Agent/项目共享（19.4） |
| project 必填 | 删 recall 的 project_id 保存 | 禁保存 + 红字「记忆读写须带 project_id」 |
| critical 极简 | scene=critical 设 mode=minimal | 自动回落 null + toast（16.5） |
| 双通道兜底 | 主通道 Webhook 熔断 OPEN | 卡片 DEGRADED，仅补偿通道工作，提示延迟 5min |
| 密钥脱敏 | 填 API Key | 界面恒显示 `[API_KEY:xxx]`，轮换后宽限期内旧 Key 有效 |
| 测试链路 | 发测试 recall | 显示注入预览 + request_id，点击开审计页 |
| **一键接入（19.9）** | 点 ⚡ 自动发现 | 四段进度条跑完，3 个本机 Agent 自动出现卡片（P0/P1/P2 打标），默认只读召回 + 双通道 + project 共享，各自记 `auto_bind` 审计 |
| **撤销自动绑定** | 点某卡「撤销」 | 该 Agent 回到 ONBOARD，记 `unbound`，其余绑定不受影响 |
| **P2 敏感动作** | 自动绑定 Codex(P2) 后开写入 | 弹确认「P2 兜底 Agent 开启写入需确认」，确认后才放行 |
| **发现兜底** | 某 Agent 无信号（MCP/进程/心跳均无） | 卡片标「未发现信号，需手填端点」，仅此类才需手动 |
| **按端置灰（19.10）** | Web 端打开 P10 | 顶部显「当前端：Web（仅注册表+心跳）」，「本机进程」信号源置灰不可选 |
| **审计记端（19.10）** | 桌面端完成一键接入 | `auto_bind` 审计含 `form:desktop`；Web 端则 `form:web`，可归因发现于哪个端 |
| **CLI 一键（19.10）** | Linux 端跑 `memagent discover --form cli` | 读系统级注册 + 进程探测，无 GUI 四段条，结果落终端表格 |
| **全端同账号同步（19.11）** | 桌面端写一条项目记忆，Web 端同账号登录 | 5min 内 Web 端命中该记忆（服务端镜像），审计 `form:web`；移动端离线写本地，回传 SHA-256 幂等不重复 |

## 9. 部署端字段（19.10 / 19.11，按确认的端谱）

> 端谱（方案 A + TS 内核 + Rust/WASM 向量层，19.11）：桌面（P0 主源）/ Web / 移动 / macOS / Linux 系统（CLI 装在 Linux）/ 通用 CLI。内核 TypeScript，向量检索性能瓶颈切 Rust/WASM。

| 字段 | 控件 | 默认 | 校验 | 联动 | 异常态 |
|---|---|---|---|---|---|
| `form` 当前端 | 只读徽标（运行时注入：desktop/web/mobile/mac/linux/cli） | 运行时检测 | 不可手填 | 决定①扫信号源可用项 + 数据落点 + 反代理来源 | — |
| 信号源可用项 | 复选组按 `form` 自动置灰 | 桌面全开；Web 关「本机进程」；移动关「本机进程/注册表」；CLI 关「Webhook 心跳」改命令 | 19.10 矩阵 | 置灰项不可勾、不渲染发现 | 「当前端不支持该信号源」 |
| 数据落点 | 只读回显 | 桌面/CLI=本地库（SQLite+DuckDB，Rust/WASM 向量）；Web/移动=服务端镜像；mac=桌面本地库；Linux=系统库 | 19.4 / 19.11 | 切端走 5.1 对账 | 同步中显示进度 |
| 同步角色 | 只读 | 桌面=主源；Web/移动/mac=镜像；CLI/Linux=按 team_id 独立 | 19.11 | 同账号自动同步 | 离线=本地先写回传 |
| `form` 审计 | 自动写入 | 每次 `auto_bind`/`sync`/`recall` 记 `form:<端>` | 必记 | 审计页按端过滤 | — |
