## P13 大模型配置页（13.2 / 6.1 / 2.4.3 / 7.2）

### 向量模型（13.2）
| 字段 | 控件 | 默认 | 校验 | 联动 | 异常态 |
|---|---|---|---|---|---|
| `model` | 下拉 | bge-m3（1024d 本地） | 枚举：SentenceTransformer(384/本地) / bge-m3(1024/本地) / DeepSeek-embedding(768/云端) | 选模型→带出维度+部署方式 | 云端需 Key 才可用 |
| `dims` | 只读（随 model） | 1024 | 随 model 联动 | 改维度→「需重建向量索引」提示 + 数据量估算（2.3） | 重建中禁用切换 |
| `deploy` | 只读（本地/云端） | 本地 | 随 model | 云端→显示 Key 脱敏槽 | Key 缺失=不可用 |
| 重建索引 | 按钮 | — | — | 触发重建任务，估时提示 | 完成前禁用 |
| 连通测试 | 按钮 | — | — | 嵌入 N 条样例，回显延迟 | 失败=模型不可用 |

### LLM 模型（本地 + 网络，按用途）
**用途枚举**（4 行，各可独立配置）：`write`(写入提取 2.2) / `judge`(查重 llm_judge 6.1) / `rerank`(LLM 重排 2.4.3/17.8) / `growth`(自生长回归 7.2)。

| 字段 | 控件 | 默认 | 校验 | 联动 | 异常态 |
|---|---|---|---|---|---|
| `local_model` | 复选 + 下拉 | 按用途（llama3:8b / 本地回归） | 本地已部署列表 | 与网络二选至少一 | 两者都关=该用途不可用 |
| `net_model` | 复选 + 下拉 | 关闭（judge 默认开） | 端点 URL + 模型名 + Key | 勾选→展开端点/Key 槽 | 端点空禁勾选 |
| `endpoint` | 文本（脱敏） | 按模型 | https 校验 | Key 恒脱敏 [API_KEY:x]（4.1） | 不可明文回填 |
| `temperature` | 数字 | judge=0.0 / write=0.2 | 0–2 | judge 强制 0.0（判重需确定性，锁灰） | — |
| `timeout_s` | 数字 | 30 | >0 | — | 超时触发回退 |
| `fallback_local` | 开关（恒开） | 开 | **不可关**（R，审计 llm_fallback） | 网络失败→自动回退本地 | — |

**critical 闸门**（rerank 行专属）：`critical_rerank_on` 默认开，且**仅当本次会话 LLM 调用在预算内才触发**（2.4.3 / 17.8），失败回退本地并记审计。

### LLM 反代理（19.8，用任意接入 Agent 自带的免费/低价模型给记忆助手干活，可跨 Agent、按成本择优）
**动机**：宿主或第三方任一已接入 Agent 自带免费或**低价**模型；记忆助手跑提取/判重/重排时直接走该 Agent 的模型通道，**不额外掏（或少掏）模型钱**，且**不局限于宿主，可跨 Agent 借用算力并按价格选最划算的**。

| 字段 | 控件 | 默认 | 校验 | 联动 | 异常态 |
|---|---|---|---|---|---|
| 全量模型映射 | 表格（跨所有已接入 Agent 的免费/低价模型一张表：Agent·模型·档位·单价·免费额度·当前余量） | — | — | 行可勾选；勾选驱动 `agent_model` 与 manual 来源 | 无接入 Agent=空表 |
| 来源 `source` | 每用途单选：本地 / 网络 / **反代理** | 本地 | 互斥 | 选反代理→带出全量映射 + `proxy_select_mode` + 额度/成本条 | 未接 Agent 时反代理项置灰 |
| `agent_model`（**多源**） | 多选（在全量映射里勾选，**用户自己选**） | 首个免费模型 | 必为免费或声明为低价档 | 展示各来源 免费额度/单价 + 剩余；manual 模式按勾选调用 | 付费高价档需显式开启 |
| 选择模式 `proxy_select_mode` | 每用途单选：**auto / manual** | auto | — | **auto**=系统自动择优（**先免费、后低价**，见下行）；**manual**=按用户在映射里勾的来源调用，仅所选源超限/失败才回退；**用户随时可定**，切换记审计 | manual 且勾选源全不可用=回退本地 |
| 低价单价上限 `proxy_price_cap`（**用户定，不可超**） | 数字输入（¥/千，可=0） | 0.02 | 0 ≤ 值；=0 即禁用所有付费低价 | **auto 低价源只挑单价 ≤ 上限的**；上限=0 时 auto 仅用免费源；超限源自动停用转免费/本地 | 用户调小上限，超限低价源即被排除 |
| 自动择优顺序（auto） | 只读（两步） | ①免费源→②低价源 | — | 先免费（按额度余量），免费耗尽/不足才用低价（单价 ≤ `proxy_price_cap`，同档按质量排）；质量优先开关可切 | 无免费且无合格低价=回退本地 |
| `proxy_budget` | 免费额度上限（次/月，逐来源） | 各来源声明额度 ×0.9（留 10% 余量） | ≤ 声明额度 | 实时额度条；临上限降权、超限回退本地 | 额度满=该来源停用 |
| `proxy_cost_cap` | 低价付费成本上限（¥/月，逐来源） | 按用途预算 | >0 | 超成本上限该低价来源停用 | 超上限转其他来源/本地 |
| 优先级 | 只读 | auto：`proxy(免费/低价, 自动择优, 成本最低优先) > 本地 > 网络(付费)`；manual：按勾选来源，全不可用才回退 | 可每用途覆盖 | 覆盖后记审计 | — |
| 审计 | 只读回显 | `llm_proxy_source=agent:<name>` + 本次实际花费 + 生效模式 auto/manual（**可跨 Agent**） | 必记 | 回退另记 `llm_fallback` | — |

**红线（反代理专属，R7–R12）**：
| # | 约束 | 出处 |
|---|---|---|
| R7 | 反代理只走**免费或声明为低价的档位**；付费高价位模型须用户显式开启且受单价/成本上限约束 | 19.8 |
| R8 | 额度（免费）与成本（低价付费）计数实时回写，逐来源留 10% 余量，**不耗尽任一 Agent 免费额度**、低价档不超 `proxy_price_cap`（单价）与 `proxy_cost_cap`（月） | 19.8 |
| R9 | 调用方仍为记忆助手，Agent 模型仅作算力提供方（宿主/第三方皆然） | 19.8 / 19.4 |
| R10 | 审计必记 `llm_proxy_source` + 本次花费 + 生效模式，**可跨 Agent 归因**"这次用了谁的模型、花了多少、自动还是手选" | 4.3 |
| R11 | 未接入 Agent 作反代理来源时须显式开放 LLM 端点，且**借算力 ≠ 共享记忆**（不改变其记忆隔离边界，19.4） | 19.8 / 19.4 |
| R12 | **auto 自动选择永远先免费、后低价，且低价只选用户 `proxy_price_cap` 内**；上限由用户定（可=0 禁用付费），系统不可越限烧钱 | 19.8 |

**验收用例（反代理，C7–C12）**：
| 用例 | 期望 |
|---|---|
| C7 写提取反代理 auto 模式挂 2 源（claude-code:claude-free 免费 + codex:gpt4o-mini 低价 ¥0.01/千） | 系统自动成本择优：免费 claude-free 优先；记 `llm_proxy_source`+花费+模式=auto（跨 Agent） |
| C8 免费源额度用满 90% | 该源临上限降权提示，满额停用并转低价源/本地；低价源超 `proxy_price_cap` 单价或 `proxy_cost_cap` 月成本同样停用 |
| C9 只勾付费高价档做反代理 | 拒（R7），须选免费/低价档，或显式开启并设单价/成本上限 |
| C10 挂未接入 Agent codex 作反代理 | 须开放 LLM 端点才可用（R11），仅借算力不共享其记忆 |
| C11 切到 manual，只勾 claude-free，claude-free 额度满 | 不再自动转低价源（manual 按勾选），claude-free 不可用→回退本地；记模式=manual |
| C12 用户 auto↔manual 随时切换 | 切换即生效并记审计 `model_config`（proxy_select_mode 变更），无缓存残留 |
| C13 auto 模式 `proxy_price_cap`=0.02，有 ¥0.03/千 的低价源 | 该源被排除（超单价上限 R12），auto 只用 ≤0.02 的低价源或免费源；把上限调大后该源才可选 |

## P14 自我净化与生长页（6.1 / 6.2 / 7.1 / 7.2 / 13.3）

### 自净化（6.1 五维 + 6.2 短路嫁接）
**五维评分**（只读，来自 6.1 权重）：`semantic 35% / keyword 20% / entity 15% / structure 10% / llm_judge 20%`，`llm_judge` 维度依赖 P13 的 judge 模型。

| 字段 | 渲染 | 说明 |
|---|---|---|
| `score`（综合分） | 数字 + 进度 | 加权平均（6.1） |
| `threshold`（按层） | L1 .70 / L2 .75 / L3 .80 / L4 .85 / L5 .90 / L6 .90 | 6.1 阈值表 |
| `is_duplicate` | score ≥ threshold 判定 | 6.1 |
| 短路嫁接路径 | 流程图：写入→逐层查重→命中层即合并停止 | 6.2 |
| 24h 统计 | 短路命中数 / 合并数（15.2）/ 查重耗时 | 6.2 |
| 换样本 | 「重新判重」按钮 | 6.1 |

**开发者可调**：五维权重（和=1.0，R 校验）、逐层阈值（L1 低→L6 高递增，R 校验单调）。

### 自生长（7.1 指标 + 7.2 优化 + 7.2 收益 + 13.3 调度）
**反馈指标（7.1，只读，每次检索自动记录）**：`hit_rate / confirmed / rejected / low_quality_ratio / level_stats.L6 / latency_ms`。

**五项自动优化（7.2）**，各带触发条件 + 当前状态徽标：
| 项 | 触发条件 | 动作 | 审计 |
|---|---|---|---|
| ① 降阈值 | hit_rate < 0.3 | adjust_threshold(lower) | 阈值变更 |
| ② 优化关键词提取 | L6 < 0.5 | refine_keyword_extraction | `keyword_refined` |
| ③ 加速遗忘 | low_quality_ratio > 0.4 | accelerate_decay | 衰减变更 |
| ④ 预建索引 | 高频查询 Top20 | build_pre_index | 索引构建 |
| ⑤ 权重回归 | 每周日 03:00 | regress_mode_weights | `weight_tuned` |

**自生长收益（7.2，联动效果看板）**：`Δ = 调权重后命中率 − 调权重前命中率`；曲线展示 `weight_tuned` 触发点（13.3 每周日 03:00）。可「手动触发一次自生长」。

**调度（13.3，只读时间轴）**：每日 02:00 衰减 / 08:00 裁决提醒 / 每周日 03:00 自生长 / 每月 1 日 04:00 归档。

|---|---|---|
