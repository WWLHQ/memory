# 多 Agent 记忆助手 — UI 页面设计

> 配套文档：《需求规格书》。本文件定义各功能页面的组件、字段与线框，章节号引用以规格书为准。
> 布局基线：左侧导航（≈220px）+ 中央主区 + 右侧上下文面板（≈320px，可折叠）。移动端退化为单栏 + 底部 Tab，上下文面板转全屏抽屉。

## 0. 信息架构（IA）

```
导航分组
├─ 记忆
│  ├─ 检索（页面 1）
│  ├─ 记忆管理（页面 8）
│  └─ 用户反馈（页面 9）
├─ 接入
│  └─ Agent 接入配置（页面 10）
├─ 参数
│  ├─ 写入（页面 2）
│  ├─ 生命周期（页面 4）
│  ├─ 全局参数（页面 5）
│  └─ 大模型配置（页面 13）
├─ 治理
│  ├─ 冲突裁决（页面 7）
│  ├─ 审计日志（页面 11，独立窗口）
│  ├─ 日志记录（页面 15，运行日志 + 异常 + L0 查阅授权）
│  ├─ 监控仪表盘（页面 6）
│  ├─ 自我净化与生长（页面 14）
│  └─ 账号与安全（页面 12）
└─ 全局上下文
   └─ 租户/团队切换器（顶栏，贯穿所有页面，见 0.1）
```

> **页面 0 登录页 与 页面 16 首页（Dashboard）为前置/落地页**，不在上述导航分组内（登录后才进入导航），见 §0.2 / §0.3。

### 0.1 全局租户上下文（3.1 / 3.2 / 18.2-A）

**所有数据类页面共享的顶栏上下文**，未显式标注的页面均默认携带：

| 全局字段 | 取值 | 规格书 |
|---|---|---|
| 当前租户 `enterprise_id` | ent_001 | 18.2-A |
| 当前团队 `team_id` | team_001（可切换） | 18.2-A |
| 当前用户 `user_id` | user_001 | 18.2-A |
| 视角 | 个人 / 团队 / 企业（按 3.2 矩阵过滤可见范围） | 3.2 |
| 会话 `session_id` | sess_abc（跨会话项目上下文，9.1） | 18.2-D |

**访问控制**（3.2）：个人记忆他人不可见；团队记忆跨团队需"已共享"标记；密码哈希仅 Admin 脱敏可见。数据类页面列表/详情默认按当前视角 + 租户过滤。

### 0.2 首页（P0，落地页 = 直接进入，18.2-A / 19.10 / 19.11）

> **首页是打开软件后的第一屏，也是功能 Dashboard，不需要先登录才能看**。首页按当前账号登录态自适应：
> - **已登录**：显示当前端&同步状态 + 功劳 4 卡 + 异常速览 + 活跃记忆 + 待办。
> - **未登录**：功能区（功劳/异常/活跃/待办）**灰置只读**，顶栏仅保留「▶ 登录」按钮（点击弹出登录卡片，见 §0.3）；团队由**管理员在账号页（P12）分配**，用户侧不可选。
> 全端同账号云同步（19.11）：登录即确定同步身份（user_id + 管理员分配的 team_id），各端同账号数据互通。

**首页区块**：
| 区块 | 内容 | 数据源 |
|---|---|---|
| 顶栏（登录态自适应） | 已登录：`你好，user_001 · 团队 team_001（管理员分配·只读）· 当前端[桌面·主源] · 已同步 2 分钟前 · [登出]`；未登录：`欢迎使用记忆助手 · 未登录 · [▶ 登录]` | 18.2-A / 19.10 |
| 当前端 & 同步状态 | `form` 徽标（自动识别，19.10）+ 同步连接（主源/镜像/离线）+ 最后对账时间 | 19.10 / 19.11 |
| 账号 & 团队（只读） | 当前 user_id + **team_id（管理员分配，只读，不可切）** | 18.2-A / P12 |
| 功劳 4 卡（19.7 口径） | 🪙 Token 节省 / ⚡ 效率提升 / 🔁 跨 Agent 复用 / 💸 模型成本节省（反代理） | 机制演示看板 |
| 异常速览 | 置顶 error（熔断/同步失败/额度超限），可跳日志页 P15 | 4.3 / P15 |
| 活跃记忆 | 近 1h 召回 Top N + decay_class + 命中质量 | 12.1 |
| 待办 | 9.7 待裁决数（跳 P8）+ 反代理临上限提醒（跳 P13） | 9.7 / 19.8 |

> 未登录时：功劳 4 卡 / 异常速览 / 活跃记忆 / 待办 显示占位「未登录，登录后可查看」（灰置），仅顶栏「▶ 登录」可点；登录成功后整页刷新为已登录数据。

**红线**：① 首页数字全部**可点溯源**到 request_id / 审计（4.3）；② 离线端（移动）显示"离线 N 条待回传"（pending_sync）；③ 不暴露内部参数名（17.3，用业务文案）；④ **团队只读**（管理员分配，用户不可自选，P12）；⑤ 首页**不阻塞登录**——未登录也能进首页（功能区灰置）。

**线框（已登录态）**：

│ 你好，user_001 · 团队 team_001（管理员分配）· 当前端[桌面·主源] │

### 0.3 登录卡片（首页内弹出子视图，非独立前置页，4.1 / 4.2 / 18.2-A / 19.10）

> 首页顶栏点击「▶ 登录」后**弹出**（未登录态）。登录即确定同步身份；**团队由管理员分配，不在此选择**。

**字段**：
| 字段 | 控件 | 校验 | 联动 | 异常态 |
|---|---|---|---|---|
| 账号（user_id / 邮箱） | 输入 | 非空 | 登录成功注入 18.2-A 全局上下文 | 不存在→「账号未注册」 |
| 密码 | 密码框（4.2 策略实时校验） | 命中 forbidden_patterns 即拒 | 错 5 次锁 15min（4.2） | 「密码错误，已记审计」 |
| 端形态 `form` | 自动识别（桌面/Web/移动/mac/Linux/CLI，19.10） | 只读 | 决定后续发现能力与数据落点 | — |
| 登录方式 | 密码 / 扫码（Web）/ 系统密钥（macOS/CLI，可选） | 按端 | CLI 无 GUI，用 `memagent login` 命令 + 非交互 token | — |

> **团队（team_id）不在登录卡片出现**：由管理员在账号与安全页（P12）分配给用户，登录后首页只读展示（§0.2）。

**红线**：① 登录必记审计（`action=login · form:<端>`，4.3）；② 密码哈希存储、传输加密（4.1），界面不回显；③ 同步身份=账号（user_id + 管理员分配的 team_id），**同账号跨端自动同步**，不同账号不互通（19.11 §1）；④ 团队只读、管理员分配（P12）。

## 1. 检索页（13.5 / 2.4.3 / 15.3）

**定位**：默认落地页。查询框驱动，结果列表 + 命中高亮 + 生效模式透明化。

### 请求字段（13.5）
| 字段 | 说明 | 控件 |
|---|---|---|
| `query` | 用户问题 | 输入框 |
| `user_id` | 当前用户（18.2-A） | 全局租户上下文自动注入 |
| `enterprise_id` | 当前企业（18.2-A） | 全局租户上下文自动注入 |
| `scene` | default / task_start / history_query / critical | 下拉（高级展开） |
| `mode` | 可空；top_insight / fact_first / event_replay / pattern_reasoning / minimal；null=自动分流（2.4.4） | 下拉，默认"自动" |
| `session_id` | 跨会话项目上下文（9.1，18.2-D） | 可选输入 / 自动继承 |

### 响应展示字段（13.5）
| 字段 | 展示 | 控件 |
|---|---|---|
| `hits[]` | 结果列表（逐条 `memory_id` 18.2-B） | 列表 |
| `scene` / `mode` | 实际生效场景与模式 | 生效模式横幅 |
| `secondary_mode_hint` | 次模式降级注入 {mode, content≤200t, note} | 横幅折叠 |
| `hit_keywords` | 自动分流命中关键词 | 横幅标签 |
| `request_id` | 召回请求 ID（18.2-E） | 横幅可复制 + 跳审计 |
| `payload_tokens` | 进 1500 软上限（2.4.1） | 预算条 |
| `pipeline_llm_tokens` | 召回链路 LLM 消耗 | 预算条 |
| `stage1_count` / `stage2_count` | 双路粗召回→打分漏斗 | 漏斗图 |
| `rerank_applied` | 是否 LLM 重排 | 标记 |
| `cold_recall` | 是否触发 Cold/dormant 补查（15.3） | 标记 |
| `evidence_thin` | 极简逃生阀（2.4.3）：true 时升级提示 | 黄色警示 |
| `budget_breach` / `breach_detail[]` | 是否裁剪 + 被裁层级/条数 | 预算面板 |
- **生效模式横幅**（响应头部）：显示实际生效的 `scene` / `mode`、`hit_keywords`、`secondary_mode_hint`；`evidence_thin=true` 时显示黄色「证据不足」警示与升级提示；`cold_recall=true` 时标记「已补查 Cold/dormant」。
- **结果列表**：每条显示内容摘要、标签、`decay_class` 分层徽标、freshness/importance/confidence 三指标条；`pinned` 条置顶且免检进候选；`locked` 条带锁图标。
- **预算面板**：`payload_tokens` / `pipeline_llm_tokens`、`stage1_count → stage2_count` 漏斗、`rerank_applied`、`budget_breach` + `breach_detail`。
- **上下文面板**：选中条记忆完整内容 + 关联记忆 + 命中片段定位。

### 线框

## 4. 生命周期页（9.10 / 17.5）

**定位**：单条 / 批量记忆的状态机**查看**与衰减参数**调参**，一屏内同时支持"看"与"改"。

### 状态机字段（9.10）
- **状态值**：`active / hibernating / archived / deprecated / stale / dormant`（9.10.1 状态定义）。
- **转换规则**：按 9.10.4 / 9.10.6 完整转换表，选中态高亮可执行迁移（如 active→hibernating 触发条件、stale→active 重新校验）。
- **deprecated 关联字段**（9.7 / 16.2）：`replaced_by`（指向替代记忆的 memory_id）、`replaced_at`（时间戳）——废弃记忆可跳替代对象详情。

### 调参字段（17.4 / 17.5）
| 字段 | 说明 | 控件 |
|---|---|---|
| `half_life_days` | 半衰期（17.5） | 滑杆/输入（可写） |
| `confidence` | 可信度 0–1 | 滑杆（可写） |
| `importance` | 重要度 0–1 | 滑杆（可写） |
| `access_count` | 召回命中次数（不含 confirm/reinforce，17.4） | 只读 |
| `reinforce_count` | 确认/强化次数（走 confidence 通道，17.4） | 只读 |
| `pinned` | 置顶（免检进候选，17.8 / AC-03） | 开关 |
| `locked` | 锁定（豁免后台衰减/归档/合并/摘要，17.4） | 开关 |
| `archived` | 归档标记 | 只读（由状态机驱动） |
| `decay_class` | hot/warm/cold/archived/dormant（15.3） | 徽标（只读） |
| `merged_from` / `merged_into` | 合并谱系（15.2） | 只读链接 |
| `created_at` / `updated_at` | 时间戳 | 只读 |
| **freshness 预览** | = 0.5^(age/half_life)，age = now − `last_access_time`（17.5） | 随调参实时刷新（只读） |

- **批量筛选 + 迁移**：按 `decay_class`、状态、`confidence` 区间过滤；批量执行迁移（如 stale→archived 超时归档，9.10.4）。
- **权限**：`locked=true` 仅查看不可调参；调参提交写审计（4.3，action=lifecycle_change，含 `request_id` 18.2-E）。

### 线框
```
┌────────────────────────────────────────────────────────────┐
│ 状态机(查看): [active] ⇄ [hibernating] → [archived] → [dormant] │
│                  ↘ [stale] →(校验)→ [active]               │
├────────────────────────┬───────────────────────────────────┤
│ ■ mem_017 [active]      │ 调参(可写)                        │
│ ■ mem_023 [stale]       │ 半衰期 [30d]  置信度 [0.62↔]      │
│ ■ mem_045 [dormant] 🔒  │ 重要性 [0.7↔]  (freshness=0.41)  │
│ 筛选: 状态[▾] 层[▾] 置信[…] │ access[12·只读] reinforce[3·只读]│
│ [批量迁移▾]            │ [应用调参] → 写审计                │
└────────────────────────┴───────────────────────────────────┘
```

## 5. 全局参数页（17.6 / 13.5 / 2.4.3）

**定位**：面向终端用户的低心智配置；开发者模式暴露底层参数。**不向普通用户暴露复杂参数名（17.6 约束）。**

### 普通配置字段（17.6，文案化，不暴露参数名）
| 配置项 | 取值 | 说明 |
|---|---|---|
| 遗忘速度 | 慢 / 中 / 快 | 映射 `half_life_days` 档位 |
| 保留时长 | 长期 / 数月 / 数周 / 短期 | 映射自动归档阈值 |
| 自动整理 | 开 / 关 | 后台合并/摘要任务（15.2 / 17.10） |
| 重要程度 | 普通 / 重要 / 锁定 | 映射 importance 档位 + `locked`（17.3） |

### 知识库策略表（17.6 可编辑）
逐行编辑六类知识库默认值：
| 知识库 | 默认半衰期 | 自动归档 | 默认自动合并 |
|---|---|---|---|
| 关键事实 | 365 天 | 730 天 | 否 |
| 个人偏好 | 180 天 | 365 天 | 谨慎开启 |
| 工作项目 | 30 天 | 90 天 | 是 |
| 任务状态 | 7–14 天 | 30 天 | 是 |
| 对话上下文 | 1–3 天 | 14 天 | 否 |

## 13. 大模型配置页（13.2 / 6.1 / 2.4.3 / 7.2）

**定位**：管理记忆助手用到的两类模型——**向量模型（embedding）** 与 **LLM 模型**（本地 + 网络），供写入提取、查重、重排、自生长回归使用。

### 字段
**向量模型（13.2）**：
| 字段 | 取值 | 说明 |
|---|---|---|
| 模型 | SentenceTransformer (MVP) / bge-m3 (进阶) / DeepSeek embedding (可选云端) | 下拉 |
| 维度 | 384 / 1024 / 768 | 随模型联动 |
| 部署 | 本地 / 云端 | 本地零依赖；云端需 Key |
| 切换/重建索引 | 按钮 | 改维度需重建向量索引（提示） |

**LLM 模型（本地 + 网络 + 反代理，按用途）**：
| 用途 | 本地模型 | 网络大模型 | 反代理（Agent 免费模型，19.8） | 说明 |
|---|---|---|---|---|
| 写入提取（L1→L6 精炼，2.2） | ✓ | ✓ | ✓ | 生成各层内容 |
| 查重 `llm_judge`（6.1，权重 20%） | ✓ | ✓ | ✓ | 判断是否重复 |
| LLM 重排（2.4.3 / 17.8） | ✓ | ✓ | ✓ | critical 场景默认开 |
| 自生长权重回归（7.2，每周） | ✓ | ✓ | ✓ | 调 mode_weights，记审计 |
| 冷层摘要（15.3 L2 占位符） | ✓ | ✓ | ✓ | ≤200t 占位符生成 |

- 每用途可选「本地 / 网络 / **反代理**」来源，优先级 `proxy(先免费 → 后低价≤单价上限) > 本地 > 网络(付费)`，可覆盖（19.8）。
- **反代理**（19.8）：
  - **全量映射视图**：把**所有已接入 Agent**（宿主 / 第三方 / 开放端点的未接入 Agent）的免费/低价模型**一张表列全**（Agent · 模型 · 档位 · 单价 · 免费额度 · 当前余量），用户**自己勾选**任意来源与模型。
  - **两种选择模式（用户定，`proxy_select_mode`）**：**auto（系统自动选）**——**先免费、后低价**，免费额度耗尽才用低价，且低价只选**单价 ≤ 用户上限**（`proxy_price_cap`，可设 0 禁用所有付费）；**manual（用户自己定）**——按全量映射里的勾选来源调用，所选来源超限/失败才回退。默认 auto，**用户随时可切换**，切换记审计。
  - **额度/成本保护**：`proxy_budget`（免费额度上限，留 10% 余量）+ `proxy_price_cap`（低价**单价**上限，用户定不可超）+ `proxy_cost_cap`（低价**月成本**上限），超限自动回退本地（审计 `llm_proxy_source` + 本次花费 + 生效模式 / `llm_fallback`）。
- **本地模型选择**：下拉本地已部署模型（如 ollama 列表），显示显存占用预估。
- **网络大模型**：端点 URL + 模型名 + Key（脱敏）+ 温度/最大 token 参数。
- **回退策略**：网络模型不可用时自动回退本地模型（写审计 `llm_fallback`）。
- 参数：温度、max_tokens、超时（各用途可配）。
