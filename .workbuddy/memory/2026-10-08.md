## P0 修复：真实首页 dev 模式白屏（交付前自测发现）
- 现象：dist 产物 E2E 全绿，但 npm run dev 打开 index.html 空白，#root 长度 0。
- 真因（浏览器实测）：tenantContext.tsx 顶层 import loginService（连带 hash.ts 的 node:crypto）。Vite **dev 模式**不 externalize node 内置模块，直接抛 `Module "node:crypto" has been externalized... Cannot access "node:crypto.scryptSync"`，中断整个模块图 → React 不挂载 → 白屏。构建产物会 externalize 故不暴露问题（此前 E2E 测 dist 因而漏测）。
- 修复：tenantContext 去掉顶层 import loginService；默认 loginFn 改为同步 no_account（前端不做本地密码校验，§4.1 密码只走后端），保持同步语义以免破坏组件测试。T5/T6/T7/T9 测试改为显式注入 `loginFn={localLogin}`（正确的依赖注入用法）。
- 验证：dev 模式 #root=1376、pageerror 空；typecheck 0 错；单测 146 全绿；全量 E2E 13 passed。
- 教训：**E2E 必须同时覆盖 dev 与 dist 两条路径**，只测 dist 会漏掉 dev 白屏。

## 修复：双击启动脚本一闪而过
- 现象：双击启动脚本窗口一闪而过，无法使用。
- 根因：bat 内用 `start` 派生子窗口，父 bat 执行完立即退出，Windows 连带回收子窗口。
- 修复：改为 .cmd —— 后端最小化后台运行（`start /MIN /D "%~dp0"`），前端 `call npx vite ...` 前台驻留，末尾 `pause` 兜底；路径用 `%~dp0` 不再硬编码。另附 start.ps1（PowerShell 版，最稳）。
- 注意：测试遗留进程占用 5180/8200 会导致端口冲突，需先 taskkill 释放。
