## 修复：直接双击 overview.html 白屏 + start 脚本竞态

- 现象：用户双击 `overview.html`（地址栏 file:///…）→ 白屏。
- 根因：`overview.html` 是 Vite 入口，只引用 `/src/web/overview/overviewEntry.tsx`，靠 Vite 现场编译 TSX；`file://` 无法编译、也取不到 `/src/…`，故白屏。**该项目页面必须走 dev server，不能直接开 html 文件。**
- 真凶 2（崩溃）：在 Git Bash 里 `npx vite --open /overview.html`，MSYS 会把 `/overview.html` 路径转换成 `D:/overview.html`，vite 拿它当 URL 去 http.get → `TypeError [ERR_INVALID_PROTOCOL]: Protocol "d:" not supported`，**vite 进程直接崩溃**。
  - 规避：命令行 `--open` 一律用**完整 URL**（`http://127.0.0.1:5180/xxx.html`），或在 bash 里不要传 `--open`（改用 vite.config 的 server.open）。
- 修复：
  - `start-overview.cmd` / `start-home.cmd`：删掉「启动 vite 之前就 `start "" http://…` 开浏览器」的竞态行，改由 vite 就绪后自动打开；`--open` 用完整 URL；`start-home` 之前会误开 overview（config open 写死）已解决。
  - 验证：真浏览器跑通览页，两视图切换 OK（首页 #btnOpenLogin、接入页 3 卡片），无 pageerror。
