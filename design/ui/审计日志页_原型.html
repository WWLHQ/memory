🔒 删除策略（4.3.2 · R-LOG8）

审计日志 append-only，禁止简单删除：普通用户界面无删除按钮；删除/归档需 Admin 权限 + 二次确认，且删除动作本身写审计 action=audit_delete（记录删除者/时间/范围），删除不可无痕（保留删除记录）。软件日志 software.log 与审计日志 audit.log 同目录独立文件（<安装根>/logs/）。
当前为普通用户：删除/归档按钮灰置（无权限）。勾选右上"切换 Admin 权限"后可见并操作。
红线：① 审计是 append-only，普通用户无删除入口；② Admin 删除/归档需二次确认 + 写 audit_delete（不可无痕）；③ 每条审计必带 request_id + form（可归因哪个端）；④ 与 P15 互补：P15 看事件流，P11 看单条记忆全链路。
