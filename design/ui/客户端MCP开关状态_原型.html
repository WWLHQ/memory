客户端 MCP 开关状态 · 三处效果页

新增原型的唯一事实来源：首页提示条 / 接入页状态行 / 壳层系统状态卡。结构、样式类名、文案、交互逐字段对齐此页；整页只说人话，不渲染原始配置内容。
场景切换点击看三处落点在每种真实状态下的呈现
① 首页 · 提示条 + MCP 接入面板对齐 overviewPage.css 的 af-alert / bad / tag / af-link 与 OverviewPage.tsx 的 McpPanel
② 接入页 · 客户端状态行对齐 McpClientsPanel.tsx 的 pill on / red / gold 与一键接入按钮
③ 壳层 · 系统状态卡对齐 ShellStatusCard.tsx，每 12 秒复核一次
判定口径与生效边界实施时逐字段对齐，不得自行简化或夸大按钮效果
状态从哪来：客户端配置里的「已禁用」标记 + 本机服务健康检查 + 审计里最近一次真实召回。三处都读不到时显示「未知」，不冒充已连接。
两件事别混：服务端在线但开关关闭 = 客户端问题；端口连不上 = 桌面端没启动。两种提示的文案与按钮完全不同。
一键打开做什么：备份原配置 → 原子写回 → 只清掉「已禁用」标记，保留其它客户端条目与请求头 → 记一条动作日志。非管理员只可查看，按钮置灰。
一键打开不做什么：客户端不会实时重读配置，所以按钮点击后只能说「已清除标记，待生效」，绝不能显示「已打开」。必须同时给「去设置手动打开」或「新开一个会话」两条出路。
点击「一键打开」后的待生效态也在本页可验：状态卡不会跳成绿色，而是显示「已清除标记 · 待手动打开或新开会话」。这是刻意设计，不是没做完。
